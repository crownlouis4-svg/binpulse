📖 Setup guide

PART 1 — Connect your ESP32

  1. Wire the sensors. One HC-SR04 ultrasonic sensor per waste section, fixed at the top of each section, facing down:
    WasteTRIG pinECHO pin
    🟢 WetGPIO 5GPIO 18
    🔵 DryGPIO 19GPIO 21
    VCC → 5V (VIN), GND → GND. Tip: a 1kΩ/2kΩ divider on each ECHO pin protects the ESP32.
  2. Install the software. In Arduino IDE: add the esp32 boards (Boards Manager), then install the PubSubClient library (Library Manager).
  3. Configure & flash. Open esp32_ecopulse.ino and edit the USER CONFIG block: your WiFi name + password (2.4 GHz network only — ESP32 can't see 5 GHz) and each section's real height in cm. Leave the broker and DEVICE_ID as they are — they already match this dashboard.
  4. Power it on. The yellow "DEMO MODE" badge disappears and your real bins appear within seconds — from anywhere, since data flows over the internet, not your local network.

PART 2 — Turn on notifications

  1. Android: open this site in Chrome → tap 🔔 Enable notifications → Allow → menu ⋮ → Add to Home screen. Full alerts then arrive like normal phone notifications (with sound), even on the lock screen while EcoPulse runs in the background.
  2. iPhone (iOS 16.4+): open in Safari → Share → Add to Home Screen → open EcoPulse from the new icon → Enable notifications → Allow.
  3. Test it now: ⚙ Settings → 🔔 Test notification. Alerts fire the moment a section crosses the threshold (default 80%) and re-arm only after it drops 10%.
